WestMC

Sprawdzanie na obecność cheatów

Pobierz WestSS.exe
  1. Pobierz i uruchom program.
    Jeśli Windows pokaże „System Windows ochronił ten komputer”, kliknij Więcej informacji i Uruchom mimo to. Program jest nowy, dlatego Windows go jeszcze nie zna.
  2. Wpisz kod od administratora (6 znaków, np. K7M2QX) i kliknij „Rozpocznij sprawdzanie”.
  3. Poczekaj chwilę i nie wychodź z serwera.
    Wynik sam trafi do administracji. Dokładniej sprawdza się jako administrator (przycisk w programie).
Wyjście z serwera, odmowa sprawdzania albo usuwanie plików w trakcie oznacza bana.

Program sprawdza tylko ślady cheatów: mody i wersje Minecrafta, uruchamiane i działające programy, kosz, ostatnio otwierane pliki i Pobrane (same nazwy plików). Nie czyta dokumentów, zdjęć ani haseł i niczego nie zmienia na komputerze.
