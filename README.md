# WestCosmetics

Autorskie kosmetyki WestMC (Fabric 1.21.4): skrzydła, czapki, aureole.

- Lista kto co ma: `gracze.json` (mod pobiera ją co 2 minuty).
- Test lokalny: `config/westcosmetics.json` w folderze gry.
- Gotowy plik `.jar`: zakładka **Actions** → ostatni build → **WestCosmetics**.

Dostępne: `skrzydla_anielskie`, `skrzydla_demona`, `skrzydla_west`, `cylinder`, `korona`, `aureola`.
